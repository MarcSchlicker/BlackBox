# BlackBox 1.2.0 - Alpha

First public CurseForge release.

- Added isolated Dimension Core farm cells with configurable size and environment upgrades.
- Added farm measurement for item, fluid, FE, and persistent-mob balances.
- Added Blackbox simulation with per-side resource routing and persistent output buffering.
- Added Stability and Output Filter upgrades.
- Added Blueprint support, farm management controls, and an English in-game handbook.
- Added optional Spawner Blackbox support for compatible modpacks.

Known limitation: BlackBox is still an alpha. Test modded machines and multiplayer server setups before relying on a profile.
